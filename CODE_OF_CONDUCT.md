# Code of Conduct

The Code of Conduct is **section 5 of [`Governance/CONTRIBUTING.md`](Governance/CONTRIBUTING.md#5-code-of-conduct)**.

This file exists only because GitHub looks for `CODE_OF_CONDUCT.md` at the repository root and surfaces it to contributors from there. It is a pointer rather than a copy: two versions of a conduct document is one version too many, and the one people would find first is the one nobody maintains.

It is not adapted from a template. It is grounded in the values this framework already asserts in `Core/AI_MANIFEST.md` — Human First, Transparency, Reviewability — because a project whose conduct rules come from somewhere other than its own principles is asking to be read as decoration.

Reporting a security problem is not a conduct matter: see [`SECURITY.md`](SECURITY.md).
