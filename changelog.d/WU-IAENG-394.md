### Fixed

- The context alert now fires when `TMPDIR` is a Windows path with a `.` or `..` component, such as `C:\x\..\y` (issue #340). The context status line refused such a `TMPDIR` and wrote its percentage under `/tmp`. The alert had no backslash handling, so it looked under the `TMPDIR` as given, and it stayed silent for that user. The directory rule now lives once, in `Adapters/ai-runtimes/claude-code/hooks/context-dir.sh`, and both hooks source it, so they can no longer name two directories. Every guard on the directory and the file is unchanged, and both hooks still exit 0 on every path, even when `context-dir.sh` is missing. `hooks/tests/context-alert.sh` runs the real writer, then the real reader, under each `TMPDIR` form. It checks that the reader finds the writer's file, or that both refuse alike.
