### Added

- A context alert, on by default (compaction plan of 23 October 2026, step C, issue #304). `Adapters/ai-runtimes/claude-code/hooks/context-alert.sh` runs on `UserPromptSubmit` and `PostToolBatch` and never blocks. When the Main Agent's context reaches `IAENG_CTX_ALERT_PCT` (default 60 %, provisional), it tells the Main Agent once to head for the Handoff: finish the Work Unit in progress, dispatch no new Employee for any other work, then run the Handoff checklist of `Templates/SESSION_STATE.md` and carry on. At the last call (`IAENG_CTX_LAST_CALL_PCT`, default the alert + 10) it says once more to write the Handoff now, then resume. The percentage is read only from the file the context status line writes, `${TMPDIR:-/tmp}/iaeng-ctx-<uid>/<session_id>.pct`, and only when the directory and file are not links, are owned by the user, cannot be written by group or others, and hold one whole number from 0 to 100. Subagents (`agent_id`) are ignored. It reads only the files of the session in the payload, never another session's. What was said is kept beside that file, never in the project, and a reading below the alert re-arms both steps. At session start, `session-start.sh` runs it to warn when the alert may come after auto-compaction, judged against the lowest compaction measured (12 points under the median). The hook starts no process when its session has nothing to hear. It is turned off by `.ia-engineering/context-hooks.off` or `IAENG_CONTEXT_HOOKS=off`, is reported by `install-hooks.sh --check` with the other hook entries, and is tested by `hooks/tests/context-alert.sh`.
