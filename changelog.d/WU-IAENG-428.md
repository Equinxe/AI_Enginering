### Fixed

- `Adapters/scripts/check-risk-map.sh` reads the paths git lists with `-z`, so a path with a character outside ASCII, a double quote, a control character or a newline is matched by its name. git prints such a name as a quoted C string by default (`docs/dé.md` as `"docs/d\303\251.md"`), and the zone patterns were matched against that form: the path took the level of a later zone than the one its name matches, a zone whose only files had such names was reported as matching no tracked file, and `--explain` printed the quoted form. A pattern is now matched against the whole name, so a newline inside it no longer splits it into two lines. The check exits 2 if it cannot create a scratch directory for the listings (WU-IAENG-428)
- `Adapters/scripts/check-pr-size.sh` reads the diff the same way, so a `linguist-generated` file with such a name is left out of the review count instead of counted (WU-IAENG-428)
