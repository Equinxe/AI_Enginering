### Security

- The commit-msg hook, `check-employee-trailers.sh`, `check-work-units.sh` and `check-risk-map.sh` now remove a carriage return only where it ends a line, as The Check Convention's shell rule 3 requires (`Standards/CODE_QUALITY_STANDARD.md`). They removed every carriage return before comparing, so a value with one inside it matched the value without it: `Employee: Platform Engi<CR>neer` was accepted as `Platform Engineer`, although git reads the carriage return as part of the value. The same applied to a roster name, a registered Work Unit id, and a risk-map pattern, level, category or declared-absent category. A CRLF file or a CRLF-terminated trailer is still read as before. Twelve cases cover the twelve sites, and each fails against the previous code (#325, SEC-IAENG-353-01, WU-IAENG-389)
