### Changed

- `Core/MAIN_AGENT_CONDUCT.md` (0.0.13), `No Direct Research`: the rule now forbids research, not reading. Research is web research or a broad sweep (a search across the repository, a walk through the file tree, a reconstruction of precedent or history from git), and it is still dispatched to a named Employee. A scoping read is allowed: the Main Agent may read a few project files and run `git status` or `git log` itself when it can name the file or command before running it and the read only locates the work. The read becomes research when the next file is known only from the last one, or when the question becomes what the code does. The plan step cannot be waived, not even by the Director's own "do it fast, no plan". The exemption closed is now "it is only a quick search"; the two sections that quoted the old "it is only one file" loophole are aligned. Director decision of 21 Oct 2026, text approved verbatim on 24 Nov 2026 (#273, WU-IAENG-451)
